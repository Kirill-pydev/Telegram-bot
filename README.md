# Телеграм-бот "Наши цветы" — Информационная система учета «Наши Цветы»

Информационная система и база данных на Python для автоматизации учета, каталогизации и управления данными в сфере флористики, ботаники или цветочного ритейла. Проект разработан как комплексное решение с централизованным хранением информации в СУБД PostgreSQL.

## 📂 Структура репозитория

*   `main.py` — основной исполняемый файл приложения (логика и запуск системы).
*   `make_db_postgresql_script.py` — скрипт автоматической инициализации, создания таблиц и настройки базы данных PostgreSQL.
*   `project_db.sql` — дамп/схема структуры базы данных со всеми связями и триггерами.
*   `data/` — директория для хранения локальных статических файлов или медиа-ресурсов.
*   `users.json` — конфигурационный файл со списком пользователей, ролей или учетных записей для авторизации в системе.
*   `requirements.txt` — список внешних библиотек и зависимостей, необходимых для работы проекта.
*   `.env.example` — шаблон конфигурационного файла для безопасного хранения конфиденциальных данных (токенов бота, доступов к БД и приватных ключей).
*   `.gitignore` — файл инструкций для Git, указывающий, какие локальные файлы и папки (например, виртуальное окружение `venv` и рабочий `.env`) не нужно отправлять в репозиторий.
*   `Описание проекта.odt` / `“Наши цветы”_compressed (1).pdf` — сопутствующая документация, методические материалы и каталог сущностей.

## 🚀 Основной функционал

*   **Управление каталогом**: систематизация данных о растениях, цветах или товарах.
*   **Многопользовательский доступ**: разграничение прав и хранение учетных записей в формате JSON.
*   **Надежная СУБД**: архитектура системы полностью опирается на промышленную реляционную базу данных PostgreSQL.
*   **Инициализация одной командой**: встроенный скрипт для быстрого развертывания структуры БД «с нуля».

## 🛠 Технологический стек

*   **Язык программирования**: Python 3.10+
*   **База данных**: PostgreSQL (интеграция через драйверы `psycopg2` / `asyncpg` или ORM)
*   **Форматы данных**: JSON (авторизация/настройки), SQL (миграции и дампы)

## 💻 Развертывание и запуск

### Предварительные требования
1. Установленный **Python 3.10+**.
2. Установленная и запущенная СУБД **PostgreSQL**.
3. Созданная пустая база данных в PostgreSQL, к которой скрипт сможет подключиться.

### Инструкция по установке

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com
   cd Third-project
   ```

2. **Настройте виртуальное окружение**:
   * Для Windows:
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```
   * Для Linux / macOS:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте конфигурацию окружающей среды**:
   Создайте файл `.env` на основе шаблона и впишите в него актуальные доступы к БД и токен вашего Телеграм-бота:
   ```bash
   cp .env.example .env
   ```

5. **Инициализируйте базу данных**:
   Перед запуском этого скрипта убедитесь, что в созданном файле `.env` (или внутри скрипта `make_db_postgresql_script.py`) указаны верные доступы к вашей локальной БД PostgreSQL (Host, User, Password).
   ```bash
   python make_db_postgresql_script.py
   ```

6. **Запустите главное приложение**:
   ```bash
   python main.py
   ```
